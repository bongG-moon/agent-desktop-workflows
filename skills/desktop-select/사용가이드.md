# 회사 PC에서 시작하기

Windows x64와 64비트 Python 3.10 이상이 필요합니다. 녹화 창에는 Python의 Tkinter가 필요합니다. 0.4.1 Windows ZIP을 풀고 `desktop-select` 폴더를 Claude Code 프로젝트의 `.claude/skills/` 바로 아래에 복사하세요. 기존 버전을 쓰고 있다면 같은 폴더를 교체하세요. 새 대화에서 저장된 작업을 사용할 수 있습니다.

### 0.4.0에서 직접 파일을 수정해서 사용했다면

0.4.1 ZIP의 `desktop-select` 폴더 전체를 기존 폴더에 덮어쓰고 Claude Code 새 대화를 시작하세요. `desktop_select.py`, `live_action.py`, `win_bridge.py`를 다른 버전끼리 섞지 마세요. 저장된 작업은 별도 위치에 있으므로 그대로 남습니다. 이 버전은 일반적인 제공자 차이를 처리하므로 FX 전용 값 설정 스크립트를 추가할 필요가 없습니다.

화면 밖 여부를 제공하지 않는 컨트롤은 실제 표시된 창의 내부 좌표와 소속으로 확인합니다. 좌표가 없는 옵션도 대상 콤보에 속한 고유한 실제 값이 확인되면 콤보의 값 쓰기 기능을 사용할 수 있습니다. 같은 값인 편집기 두 개는 서로 일치하는 근거로 인정하고, 값이 다른 경우에는 실행 전에 알립니다. 옵션 이름만으로 값을 추정하거나 쓰기 성공만으로 적용됐다고 판정하지 않습니다.

조작이나 녹화를 요청하면 최소화된 대상 창을 복원합니다. `inspect`는 복원하지 않으므로 최소화 상태의 좌표가 비어 있어도 화면 인식 실패와 구분하세요. 표 우클릭은 계속 실제 마우스를 사용합니다.

### 한 번 가르쳐 두고 값만 바꿔 실행하기

1. FX 업무 창을 열고 Claude Code에 **“desktop-select로 이 창의 조건 설정을 ‘장비 조건’이라는 작업으로 녹화해 줘”**라고 요청하세요. 녹화 창에서 **시작**을 누른 후 실제 업무 창에서 MES Setup과 Family 콤보를 차례로 선택하세요.
2. **마치고 검토**를 누르면 단계 목록을 볼 수 있습니다. 각 행을 선택하고 그 옆의 **실행할 동작**을 적으세요. 1단계에는 `MES SETUP조건을 N으로 해줘`, 2단계에는 `입력받은 변수를 FAMILY조건에 입력해줘`라고 씁니다. 미리보기에 첫 값이 **N**, 둘째 값은 실행할 때 받을 **Family**로 표시되는지 확인하고 저장하세요. 같은 단계에 `패밀리 조건`처럼 짧은 별칭도 붙일 수 있습니다.
3. 다음에는 **“장비 조건을 Family=Hybrid로 실행해 줘”**라고만 요청하세요. Family를 주지 않으면 먼저 값을 물어봅니다. **“장비 조건의 패밀리 조건 단계만 Family=Hybrid로 실행해 줘”**처럼 한 단계만 실행할 수도 있습니다.

| 각 단계의 ‘실행할 동작’에 입력할 문장 | 실행 미리보기와 실제 동작 |
|---|---|
| `MES SETUP조건을 N으로 해줘` | **지정한 값으로 선택: N**. 시연한 값이 달라도 재생할 때는 N을 선택하고 다시 읽습니다. |
| `입력받은 변수를 FAMILY조건에 입력해줘` | **실행 시 입력할 변수: Family**. 실행 요청에서 받은 값을 선택합니다. 값이 빠지면 첫 단계도 실행하지 않습니다. |

시연한 콤보는 찾았지만 선택값만 읽히지 않을 때도 그 행에 지시를 넣을 수 있습니다. 자동 해석이 어려운 표현은 **콤보 값 지정**에서 고정값이나 필수 변수를 직접 고르고 미리보기를 확인하세요. 대상 자체를 식별하지 못한 단계는 문장을 적어도 자동으로 실행되지 않습니다.

저장 후에는 “패밀리 조건 근처의 조회 버튼을 찾아 줘”처럼 주변 요소를 따로 지시할 수도 있습니다. 녹화에서 확인한 같은 업무 영역 안에 대상이 하나만 있을 때 사용할 수 있습니다.

표시된 지시를 해석할 수 없거나 문장의 대상이 녹화한 필드와 다르면 해당 행을 수정하세요. 일반 녹화에서 확인되지 않은 클릭이나 표 영역 우클릭은 검토 대상으로 남습니다. 아래의 전용 단계로 조회와 표 우클릭을 연결할 수 있습니다. 조회 버튼의 호출만 확인된 경우엔 그 자리에서 멈춥니다. 화면 결과를 확인하기 전에 재생을 반복하면 조회나 내보내기가 중복될 수 있습니다.

저장 위치는 기본적으로 `%LOCALAPPDATA%\DesktopSelect\tasks`입니다. 작업 파일에는 대상 프로그램과 창 제목, 단계별 요소 식별 정보, 직접 지정한 지시 및 값이 들어갑니다. 녹화는 시작부터 마치기까지 선택한 업무 창의 조작을 관찰하며 화면 영상과 원시 키 입력을 작업 파일에 담지 않습니다. 시연 중에는 사용자가 직접 마우스를 사용합니다. 재생은 현재 창에서 Windows 접근성 기능으로 대상을 선택합니다.

### “입력한 문장의 대상이 녹화한 요소와 다릅니다”가 나온다면

먼저 오류가 표시된 **단계의 대상**을 확인하세요. 실제 라벨이 읽히면 `gcboStatus` 같은 내부 이름 대신 해당 라벨로 연결됩니다. 라벨이 없어 내부 이름만 보이고, 그 콤보가 MES Setup이 맞다면 문장을 그대로 둔 채 **문장의 이름을 이 대상에 연결**을 누르세요. 연결 내용을 한 번 확인하면 그 이름을 별칭으로 저장합니다. 예를 들어 `MES SETUP조건을 N으로 해줘`를 현재 선택한 콤보에 연결할 수 있습니다. 이미 다른 단계에서 쓰는 이름이나 명확히 다른 라벨의 필드에는 연결되지 않습니다.

이름을 붙이지 않으려면 현재 행에서 **콤보 값 지정**으로 고정값 `N` 또는 필수 변수 `Family`를 직접 지정하거나, `이 항목을 N으로 설정`처럼 현재 대상을 가리키는 표현을 사용하세요. 같은 대상의 임시 경로만 갱신된 경우에는 입력한 문장과 변수 설정을 유지합니다. 대상 자체가 바뀌었으면 입력 문장을 유지한 채 알려 주므로 새 대상을 확인한 뒤 **동작 적용**을 눌러 다시 연결하세요.

### FX: MES Setup=N, Family는 매번 입력해서 조회부터 Excel 내보내기까지

**처음 한 번만 가르칩니다.** FX에서 해당 업무 화면을 열고 Claude Code에 **“desktop-select로 이 창에 ‘FX 조회 내보내기’라는 작업을 녹화해 줘”**라고 요청하세요.

1. **시작**을 누른 후 MES Setup과 Family를 한 번씩 선택하세요. **마치고 검토**에서 첫 행에는 `MES SETUP조건을 N으로 해줘`, 둘째 행에는 `입력받은 변수를 FAMILY조건에 입력해줘`라고 적습니다. 고정값 **N**과 필수 변수 **Family**가 각각 표시되는지 확인하세요. 아직 작업을 저장하지 않습니다.
2. **조회 후 우클릭 메뉴 가르치기 → 조회 버튼 가리키기 (3초)**를 누른 뒤 실제 폼 안의 조회 버튼에 포인터를 올립니다. 업무 화면에서 직접 조회해 결과가 나타나도록 하세요. 조회 버튼은 이번 단계에 포함되므로 별도 클릭 단계로 두지 마세요.
3. 메뉴 이름에 **첫 줄 `EXPORT`, 둘째 줄 `EXPORT TO EXCEL`**을 실제 표시와 같게 입력합니다. **데이터가 있는 지점 가리키기 (3초)**를 누르고 결과 표의 데이터 본문 안쪽을 가리키세요. 제목, 열 머리글, 스크롤 막대는 피합니다. 셀이 접근성 목록에 없어도 이름이나 ID로 같은 표를 다시 찾을 수 있으면 사용할 수 있습니다. 특정 레코드나 선택한 행만 내보내는 메뉴라면 이 위치만으로 레코드 일치까지 보장하지 않습니다.
4. **상태 글자 가리키기 (3초)**로 실제 조회가 끝났을 때의 상태 요소를 지정하고 기대 글자를 확인하세요. 글자를 읽을 수 없으면 **표 안의 완료 모양 고르기**에서 조회 중에는 사라졌다가 완료 시 나타나는 작은 표시를 지정합니다. 표 테두리, 항상 켜진 버튼, 매번 달라지는 데이터 값은 적합하지 않습니다. 조회 전부터 같은 표시라면 재생 중에 그 표시가 사라졌다 다시 나타나는 것도 관찰해야 진행합니다.
5. 파일 생성까지 확인하려면 **앱이 실제로 저장하는** 로컬 `.xlsx` 또는 `.xlsm` 파일 경로를 지정하세요. 파일명이 매번 바뀌면 이 작업만 사용하는 로컬 폴더를 지정하세요. 폴더 모드에서는 새 통합 문서가 정확히 하나 생겨야 합니다. **단계에 추가 → 저장**을 누릅니다. 파일을 지정하지 않아도 메뉴를 실행할 수 있지만 파일 생성은 확인되지 않습니다.

**다음부터는 한 문장이면 됩니다.** Claude Code에 **“FX 조회 내보내기를 Family=Hybrid로 실행해 줘”**라고 하세요. 변수 없이 요청하면 값을 먼저 받아야 하며, 그전에는 첫 단계도 실행하지 않습니다. 결과를 읽지 못하면 다음 단계로 넘어가지 않습니다. 표와 메뉴는 실제 마우스를 쓰므로 FX 창을 표시하고 재생 중에는 마우스나 키보드를 움직이지 마세요.

파일 확인은 256 MiB 이하의 통합 문서를 대상으로 합니다. 파일 감시는 저장 경로를 정해 주는 기능이 아닙니다. FX가 ‘다른 이름으로 저장’을 띄우거나 저장하지 않은 Excel 창만 연다면 직접 저장해야 합니다. `.xls`와 네트워크 폴더는 이 버전의 통합 문서 확인 대상이 아닙니다. 이전 버전에서 수동으로 남은 우클릭은 위 절차로 새 작업에 가르치세요. 회사 PC에서 처음 시험할 때는 내보낸 파일을 열어 선택한 Family의 결과가 맞는지도 확인하세요.

### 목록에서 특정 행의 버튼을 누르고 결과 확인하기

예를 들어 목록의 세 기기를 실행한다면, 먼저 관리자를 열고 실행할 세 행의 번호와 현재 상태를 확인하세요. 창 크기와 화면 배율은 시연할 때와 같게 두고 세 행이 화면에 보이게 하세요.

1. Claude Code에 **“이 창의 목록에서 행 버튼을 가르치는 녹화를 시작해 줘. 이름은 ‘기기 세 대 실행’이야.”**라고 요청합니다. 녹화 창에서 **행 버튼 가르치기 → 행 가져오기 (3초)**를 누르고 업무 창의 대상 행 위에 마우스를 둡니다.
2. 행 미리보기에서 세 곳을 지정하세요. **행을 구별하는 표시**에는 번호나 고유 이름, **클릭할 버튼**에는 ▶ 전체, **상태**에는 ‘부팅되지 않음’ 같은 현재 상태 글자를 담습니다. 다른 행에서도 계속 달라지는 숫자, 경과 시간, 포인터가 놓일 때만 나타나는 아이콘은 피하세요.
3. **실행 전 상태 기록**을 누른 뒤 업무 창에서 직접 버튼을 누르세요. 같은 행에 원하는 **최종 상태**가 보일 때 **완료 상태 가져오기 (3초)**를 누릅니다. ‘부팅 중’에서 기록하면 다음 실행부터 ‘부팅 중’을 완료로 판정하게 됩니다. **이 행에서 실행할 동작**에 `첫 번째 기기의 시작 버튼을 눌러 실행 중인지 확인`처럼 적고, 미리보기를 확인한 뒤 **단계에 추가**를 누르세요. 두 번째와 세 번째 행은 같은 버튼과 시작 상태라면 **이전 행의 완료 표시 사용**으로 시연을 줄일 수 있습니다. 행을 모두 추가하고 저장하세요.
4. **“기기 세 대 실행을 재생해 줘.”**라고 요청합니다. 재생은 가르친 행을 현재 화면에서 다시 찾고 마우스로 버튼을 한 번 누릅니다. 해당 행에서 완료 표시를 확인하면 다음 행으로 진행합니다. 이미 완료된 행은 클릭을 건너뜁니다. 중간에 멈추면 **“이 작업의 각 행 상태만 다시 확인해 줘.”**라고 요청하세요.

같은 이름의 버튼이 여러 줄에 있어도 행 번호나 이름이 구분되면 사용할 수 있습니다. 목록의 정렬 순서가 바뀌면 녹화한 번호나 이름을 따라갑니다. 담당자가 새로 상위에 올라온 행을 실행하고 싶다면 그 행을 다시 지정하세요. Windows가 목록의 행 경계를 제공하고, 버튼과 상태 표시를 화면에서 구분할 수 있어야 합니다. 작업 파일에는 직접 지정한 행 표식, 버튼, 전후 상태의 작은 화면 표본이 로컬에 저장됩니다. 행을 구별하는 데 필요한 부분만 담으세요.

### 녹화 없이 바로 지시하기

**처음에는 읽기만 해 보세요.** 회사 PC에서 실제 업무 화면을 연 뒤 다음처럼 요청합니다.

> desktop-select로 Device Setup Standard 업무 창에서 MES Setup과 Family가 각각 어느 콤보인지 보여 줘. 아직 값을 바꾸지 마.

대상이 맞으면 **“같은 창에서 MES Setup을 N으로, 확인되면 Family를 Hybrid로 선택해 줘”**라고 요청하세요. 조작 전부터 같은 값을 명확히 읽었으면 입력 없이 확인한 것으로 표시합니다. 선택을 전달한 후에도 선택값을 읽을 수 없으면 거기서 멈춥니다. 화면에 있는 옵션 목록만으로 선택됐다고 판정하지 않습니다.

**조회나 메뉴:** “업무 폼 안의 조회를 눌러 줘”처럼 같은 이름의 두 버튼 중 원하는 쪽을 알려 줄 수 있습니다. 범위 이름은 `commands`(바깥 도구 모음), `content`(안쪽 업무 폼), `conditions`(조회 조건), `condition-commands`(조건 영역 명령), `grid`, `properties`입니다. 실제로 나타난 영역만 사용할 수 있습니다. 중첩 메뉴는 먼저 부모를 펼치고 실제로 나타난 자식을 선택합니다. 표 내부나 우클릭 메뉴가 접근성에 노출되지 않으면 사용자가 메뉴를 열어 준 후 보이는 항목부터 확인할 수 있습니다. 셀을 추측하거나 선택 범위를 바꾸지 않습니다. 우클릭으로 내보낼 때는 위 FX 절차에서 메뉴 경로와 파일 조건을 함께 가르치세요.

**마우스 사용 여부**는 단계에 따라 다릅니다. 콤보와 메뉴는 Windows 접근성 기능으로 조작합니다. 행 버튼과 표 우클릭 메뉴 재생은 대상 창을 앞으로 가져오고 실제 포인터를 이동해 클릭합니다. 실제 포인터를 쓰는 단계가 끝날 때까지 마우스와 키보드를 사용하지 마세요.

**콤보에서 어디까지 읽히나:** 특정 콤보를 확인하면 현재 접근성에서 읽히는 옵션 값과 이름을 보여 줍니다. 값과 표시명이 다르면 선택한 필드의 목록 안에서만 두 가지를 대조합니다. 닫힌 콤보는 목록이나 현재값이 비어 보일 수 있습니다. 선택 요청 시에는 필요하면 그 콤보만 펼칩니다. 표시명이 중복되거나 목록 대신 표의 행/셀만 제공하는 드롭다운, 검색 전용 별도 대화상자는 임의로 값을 쓰지 않습니다. 이 경우 실제 업무 화면에서 직접 선택해야 할 수 있습니다.

문제가 생겼을 때는 다음만 구분하면 됩니다.

| 표시 | 의미와 다음 행동 |
|---|---|
| `verified` | 해당 단계의 기대값 또는 상태가 일치했습니다. 파일 조건을 지정한 내보내기에서는 새로 생성되거나 변경된 Excel 통합 문서를 확인했습니다. |
| `blocked` | 명령을 완료하지 못했습니다. 창/필드 중복, 읽을 수 없는 옵션, 비활성 컨트롤 등을 확인하세요. `expanded: true`이면 목록만 펼쳤을 수 있습니다. |
| `delivered_unverified`, `mismatch`, `uncertain` | 호출 결과를 성공으로 단정하거나 다시 누르지 마세요. 화면을 보거나 같은 대상에 `inspect`로 읽기만 하세요. |

PowerShell에서 직접 시험할 때는 스킬 폴더에서 실행합니다. 아래 제목은 **첫 명령이 돌려준 실제 제목 전체**로 바꾸세요.

```powershell
Get-Process -Name '*MenuAgent*' | Select-Object -ExpandProperty ProcessName -Unique
$fx = '<위에서 확인한 MenuAgent 프로세스 이름>.exe'
python -X utf8 -B scripts/desktop_select.py windows --exe $fx
$screen = '<실제 업무 창 전체 제목>'
python -X utf8 -B scripts/desktop_select.py inspect --exe $fx --window $screen --target 'MES Setup' --role combobox
python -X utf8 -B scripts/desktop_select.py select --exe $fx --window $screen --target 'MES Setup' --value N
python -X utf8 -B scripts/desktop_select.py select --exe $fx --window $screen --target Family --value Hybrid
```

마지막 두 줄은 한 줄씩 실행해 결과를 확인하세요. 스킬은 해당 PC에서 동작하며, 출력은 명령을 실행한 Claude Code 세션에 보입니다.
