# 회사 PC에서 시작하기

Windows x64와 64비트 Python 3.10 이상이 필요합니다. 녹화 창에는 Python의 Tkinter가 필요합니다. **0.4.3은 0.4.0 기반 실행에 자연어 녹화와 실행안 저장을 연결한 버전입니다.** ZIP을 풀고 `desktop-select` 폴더를 Claude Code 프로젝트의 `.claude/skills/` 바로 아래에 복사하세요. 기존 설치 폴더는 먼저 별도 이름으로 보관한 뒤 새 폴더 전체를 넣으세요. 일부 파일만 덮어쓰면 서로 다른 버전이 섞일 수 있습니다. 기존 녹화 파일은 삭제하지 않습니다. 0.5/0.6의 intent 형식 작업은 이 버전에서 변환하거나 실행하지 않으며 해당 버전으로 사용해야 합니다.

### 녹화 위치 + 자연어 지시 + 저장된 실행안

이 세 가지를 함께 사용할 수 있습니다. 녹화로 MES Setup, Family, 조회 버튼의 위치를 알려 주고 각 단계 옆에 문장을 적습니다.

| 단계 | 지시 예 | 저장되는 동작 |
|---|---|---|
| MES Setup | `MES Setup을 N으로 설정해 줘` | 고정값 N |
| Family | `입력받은 변수를 Family 조건에 입력해 줘` | 실행 시 필요한 변수 Family |
| 조회 | `조회 버튼을 눌러 줘` | 실제 조회 버튼 호출 |

**저장하면 원문과 실행안을 함께 보관합니다.** 다음에는 “저장한 작업을 Family=Hybrid로 실행해 줘”라고 요청하면 됩니다. 지원되는 전체 작업은 한 번의 Python 실행과 UIA 연결로 재생합니다. 매번 모델이 문장을 다시 해석하거나 전체 트리를 단계마다 분석하지 않습니다. 원본 지시가 바뀌면 이전 실행안을 버리고 다시 만듭니다.

로컬 편집란이 이해하지 못하는 자유로운 문장은 Claude Code에 **“녹화한 2단계는 Family 값은 실행할 때 받은 값을 넣으라는 뜻이야. 이 문장을 원문 그대로 두고 필수 변수 Family로 저장해 줘.”**라고 요청하세요. 현재 사용하는 모델이 의미를 한 번 해석해 구조화된 값과 함께 저장합니다. 스킬 자체가 외부 모델을 호출하지 않습니다. 예를 들어 아래 명령은 기존 작업을 보존하고 수정한 새 작업을 만듭니다.

```powershell
python -X utf8 -B scripts/desktop_select.py instruct --task "조건 조회" --only 2 --text "Family 값은 실행할 때 받은 값을 넣어줘" --mode required --argument Family --save-as "조건 조회 수정"
python -X utf8 -B scripts/desktop_select.py plan --task "조건 조회 수정"
```

문장에 나온 이름만 다르면 실제 녹화 대상을 확인한 뒤 이름을 연결할 수 있습니다. 새로운 이름을 연결한다는 이유로 다른 컨트롤을 추측해 고르지는 않습니다. UI의 고정값/필수 변수 지정과 다음 단계 이동, 삭제 기능도 그대로 사용할 수 있습니다.

**조회 뒤 내보내려면 대기 또는 완료 조건을 지정하세요.** 비동기 조회 뒤 바로 Excel을 호출하지 않도록, 처음에 “조회하고 5초 기다린 뒤 내보내기”라고 요청하면 조회 단계에 그 시간을 저장합니다. 대기를 지정하지 않은 중간 버튼은 기존 방식처럼 호출 전달에서 멈춥니다. 아래는 이미 내보내기 단계까지 녹화한 작업의 3단계에 대기를 지정하는 예입니다.

```powershell
python -X utf8 -B scripts/desktop_select.py instruct --task "조회 내보내기" --only 3 --text "조회한 뒤 5초 기다려" --mode recorded --wait-after 5 --save-as "조회 내보내기 실행"
python -X utf8 -B scripts/desktop_select.py replay --task "조회 내보내기 실행" --exe "Example.exe" --window "업무 창 제목" --set "Family=Hybrid"
```

고정 대기는 서버 조회 완료의 증거는 아닙니다. 실제 조회에 맞는 시간을 사용하거나 기존 표 메뉴 녹화의 완료 조건을 지정하세요. 행, 우클릭, 수동 단계가 섞이면 작업 전체를 기존 재생으로 처리하며 지원 단계만 골라 실행하지 않습니다. `--only`, 별칭으로 값 지정, 예전 녹화값 기본 동작도 기존 재생 규칙을 유지합니다.

원하면 녹화한 작업을 Python 업무 스킬로 만들 수 있습니다. 이 경우 `source-task.json`에 원문 녹화를, `workflow.json`에 실행할 동작을 저장합니다. 생성한 업무 스킬은 등록 당시의 복사본이므로 이후 원본 녹화를 바꿨다면 새 이름으로 다시 등록하세요.

```powershell
python -X utf8 -B scripts/python_workflow.py register --task "조회 내보내기 실행" --out ../fx-query
python -X utf8 -B ../fx-query/scripts/run.py --set "Family=Hybrid"
```

실행안 저장 위치는 `%LOCALAPPDATA%\DesktopSelect\tasks\execution-plans`입니다. 원본 작업 파일은 그대로 남습니다. 저장 공간 문제로 실행안을 만들지 못해도 이미 저장한 녹화는 없어지지 않습니다.

### 현장에서 성공한 방식: 한 번 등록하고 Python으로 실행

Claude Code에 **“desktop-select로 MES Setup은 N, Family는 매번 입력받고 조회 후 5초 대기해서 엑셀 버튼을 누르는 업무 스킬을 등록해 줘. 먼저 화면의 실제 ID를 확인해 줘.”**라고 요청하세요. 콤보와 버튼만 간단히 찾은 뒤 등록하므로 매번 전체 화면과 옵션을 분석하지 않습니다. 다음에는 **“등록한 조회 업무를 Family=Hybrid로 실행해 줘”**라고 요청합니다.

등록은 동작을 실행하지 않습니다. 콤보는 부모에 값을 한 번 쓰고 현재 값을 확인하며, 버튼은 한 번 호출합니다. 조회 후 5초는 결과를 기다리는 시간일 뿐 조회 완료의 증명은 아닙니다. 버튼 전달은 `delivered_unverified`, 전체는 `completed_unverified`일 수 있습니다. 결과 표와 Excel 창 또는 생성 파일은 따로 확인하세요. 콤보 확인 실패나 불확실한 호출 뒤에는 다음 버튼을 누르지 않습니다.

초기 등록을 직접 확인하려면 아래 순서를 사용합니다. 다음 예의 ID는 예시이므로 **현재 PC에서 찾은 실제 ID**로 바꿔야 합니다. 프로그램 이름과 창 제목도 현재 값으로 넣습니다.

```powershell
python -X utf8 -B scripts/python_workflow.py discover --exe "Example.exe" --window "업무 창 제목"
```

아래 내용을 회사 PC에 `query-recipe.json`으로 저장합니다. Family에는 `value`를 넣지 않고 `parameter`만 넣습니다.

```json
{
  "schema": 1,
  "name": "조건 조회 후 Excel",
  "exe": "Example.exe",
  "window": "업무 창 제목",
  "steps": [
    {"action": "set-value", "selector": {"automation_id": "gcboStatus", "role": "combobox"}, "value": "N"},
    {"action": "set-value", "selector": {"automation_id": "gcboFamily", "role": "combobox"}, "parameter": "Family"},
    {"action": "invoke", "selector": {"automation_id": "btnSearchData", "role": "button"}},
    {"action": "wait", "seconds": 5},
    {"action": "invoke", "selector": {"automation_id": "btnExportExcel", "role": "button"}}
  ]
}
```

desktop-select 폴더에서 등록합니다. 새 업무 폴더는 desktop-select와 같은 skills 폴더에 생성합니다.

```powershell
python -X utf8 -B scripts/python_workflow.py register --recipe query-recipe.json --out ../fx-query
python -X utf8 -B ../fx-query/scripts/run.py --read-only
python -X utf8 -B ../fx-query/scripts/run.py --set "Family=Hybrid"
```

생성되는 파일은 `SKILL.md`, `workflow.json`, `scripts/run.py` 세 개입니다. 외부 전송, 추가 EXE, CUA 드라이버 설치가 없습니다. 업무 스킬은 옆의 desktop-select 실행기를 사용합니다. 값은 실행할 때 받고, 고정값과 순서는 `workflow.json`을 수정해 바꿀 수 있습니다. 같은 이름으로 등록하면 덮어쓰지 않습니다.

위 예는 **엑셀 버튼**을 요청한 경우입니다. 우클릭의 `EXPORT → EXPORT TO EXCEL`을 요청했다면 버튼으로 바꾸지 않고 아래의 기존 0.4.0 메뉴 녹화 기능을 사용합니다. 이 단순 Python 등록기는 조건 설정, 버튼 호출, 대기를 지원하며 행과 우클릭 메뉴는 기존 녹화가 담당합니다.

### 0.4.0에서 보완한 실행 문제

| 증상 | 0.4.3 처리 |
|---|---|
| 화면에 있는데 `IsOffscreen=None` | 값 누락과 화면 밖을 구분하고, 현재 창 표시와 유효한 내부 좌표로 판단 |
| 편집 요소 두 개가 같은 값인데 충돌 | 동일 값은 일치 근거로 사용하고 서로 다른 값만 충돌 처리 |
| 옵션 좌표 0×0, 펼침 상태 미갱신 | 쓰기 가능한 부모 콤보에 SetValue 1회 후 읽기 확인 |
| 최소화 상태의 좌표 0×0 | 실제 조작 전 복원하고 다시 관찰. 읽기 전용은 창을 복원하지 않음 |
| 호환 코드 수정 시 `skill_incomplete` | 호환 처리를 핵심 브리지 밖에 분리하고 핵심 파일 검증은 별도 manifest로 유지 |
| 직접 명령 때 반복되는 전체 탐색 | 최초 라벨 탐색 후 확인 단계는 같은 ID와 현재 창 범위로 재검사 |

직접 명령과 등록 실행의 콤보 값은 실제 입력 문자열입니다. 표시 이름과 저장 코드가 다른 경우 실제 코드를 확인해서 사용하세요. 입력 후 확인이 안 되면 펼치기나 클릭으로 자동 재시도하지 않습니다. 콤보와 버튼의 접근성 호출은 마우스를 움직이지 않지만 최소화된 창은 복원됩니다. 행 버튼과 우클릭 메뉴의 물리 입력은 실제 마우스를 사용합니다.

### 한 번 가르쳐 두고 값만 바꿔 실행하기

1. FX 업무 창을 열고 Claude Code에 **“desktop-select로 이 창의 조건 설정을 ‘장비 조건’이라는 작업으로 녹화해 줘”**라고 요청하세요. 녹화 창에서 **시작**을 누른 후 실제 업무 창에서 MES Setup과 Family 콤보를 차례로 선택하세요.
2. **마치고 검토**를 누르면 단계 목록을 볼 수 있습니다. 각 행을 선택하고 그 옆의 **실행할 동작**을 적으세요. 1단계에는 `MES SETUP조건을 N으로 해줘`, 2단계에는 `입력받은 변수를 FAMILY조건에 입력해줘`라고 씁니다. **적용하고 다음 단계**으로 다음 단계에 이동하세요. 미리보기에 첫 값이 **N**, 둘째 값은 실행할 때 받을 **Family**로 표시되는지 확인하고 저장하세요. 잘못 녹화한 행은 검토 중 **선택 단계 삭제**로 지울 수 있습니다. 같은 단계에 `패밀리 조건`처럼 짧은 별칭도 붙일 수 있습니다.
3. 다음에는 **“장비 조건을 Family=Hybrid로 실행해 줘”**라고만 요청하세요. Family를 주지 않으면 먼저 값을 물어봅니다. **“장비 조건의 패밀리 조건 단계만 Family=Hybrid로 실행해 줘”**처럼 한 단계만 실행할 수도 있습니다.

| 각 단계의 ‘실행할 동작’에 입력할 문장 | 실행 미리보기와 실제 동작 |
|---|---|
| `MES SETUP조건을 N으로 해줘` | **지정한 값으로 선택: N**. 시연한 값이 달라도 재생할 때는 N을 선택하고 다시 읽습니다. |
| `입력받은 변수를 FAMILY조건에 입력해줘` | **실행 시 입력할 변수: Family**. 실행 요청에서 받은 값을 선택합니다. 값이 빠지면 첫 단계도 실행하지 않습니다. |

녹화는 **동작 위치만 알려 주고 실제 동작은 문장으로 지정**할 수 있습니다. 현재 선택값을 못 읽는 콤보도 대상이 확인되면 편집할 단계로 남깁니다. 라벨 대신 `gcboStatus`만 보여 문장과 이름이 다르면 **문장의 이름을 이 대상에 연결**로 `MES Setup`을 연결하거나 `이 항목을 N으로 설정해 줘`라고 쓰세요. 자동 해석이 어려운 표현은 **콤보 값 지정**에서 고정값이나 필수 변수를 직접 고르고 미리보기를 확인하세요. 자유 문장은 로컬의 지원 표현으로 해석하므로 모든 자연어 표현을 이해하는 것은 아닙니다. 대상 자체를 식별하지 못한 단계는 삭제 후 대상만 다시 녹화하세요. 실제 대상 없이 좌표를 추측하여 입력하지 않습니다.

저장 후에는 “패밀리 조건 근처의 조회 버튼을 찾아 줘”처럼 주변 요소를 따로 지시할 수도 있습니다. 녹화에서 확인한 같은 업무 영역 안에 대상이 하나만 있을 때 사용할 수 있습니다.

표시된 지시를 해석할 수 없거나 문장의 대상이 녹화한 필드와 다르면 해당 행을 수정하세요. 일반 녹화에서 확인되지 않은 클릭이나 표 영역 우클릭은 검토 대상으로 남습니다. 아래의 전용 단계로 조회와 표 우클릭을 연결할 수 있습니다. 조회 버튼의 호출만 확인된 경우엔 그 자리에서 멈춥니다. 화면 결과를 확인하기 전에 재생을 반복하면 조회나 내보내기가 중복될 수 있습니다.

저장 위치는 기본적으로 `%LOCALAPPDATA%\DesktopSelect\tasks`입니다. 작업 파일에는 대상 프로그램과 창 제목, 단계별 요소 식별 정보, 직접 지정한 지시 및 값이 들어갑니다. 녹화는 시작부터 마치기까지 선택한 업무 창의 조작을 관찰하며 화면 영상과 원시 키 입력을 작업 파일에 담지 않습니다. 시연 중에는 사용자가 직접 마우스를 사용합니다. 재생은 현재 창에서 Windows 접근성 기능으로 대상을 선택합니다.

### FX: MES Setup=N, Family는 매번 입력해서 조회부터 Excel 내보내기까지

**처음 한 번만 가르칩니다.** FX에서 해당 업무 화면을 열고 Claude Code에 **“desktop-select로 이 창에 ‘FX 조회 내보내기’라는 작업을 녹화해 줘”**라고 요청하세요.

1. **시작**을 누른 후 MES Setup과 Family를 한 번씩 선택하세요. **마치고 검토**에서 첫 행에는 `MES SETUP조건을 N으로 해줘`, 둘째 행에는 `입력받은 변수를 FAMILY조건에 입력해줘`라고 적습니다. 고정값 **N**과 필수 변수 **Family**가 각각 표시되는지 확인하세요. 아직 작업을 저장하지 않습니다.
2. **조회 후 우클릭 메뉴 가르치기 → 조회 버튼 가리키기 (3초)**를 누른 뒤 실제 폼 안의 조회 버튼에 포인터를 올립니다. 업무 화면에서 직접 조회해 결과가 나타나도록 하세요. 조회 버튼은 이번 단계에 포함되므로 별도 클릭 단계로 두지 마세요.
3. 메뉴 이름에 **첫 줄 `EXPORT`, 둘째 줄 `EXPORT TO EXCEL`**을 실제 표시와 같게 입력합니다. **데이터가 있는 지점 가리키기 (3초)**를 누르고 결과 표의 데이터 본문 안쪽을 가리키세요. 제목, 열 머리글, 스크롤 막대는 피합니다. 셀이 접근성 목록에 없어도 이름이나 ID로 같은 표를 다시 찾을 수 있으면 사용할 수 있습니다. 특정 레코드나 선택한 행만 내보내는 메뉴라면 이 위치만으로 레코드 일치까지 보장하지 않습니다.
4. **상태 글자 가리키기 (3초)**로 실제 조회가 끝났을 때의 상태 요소를 지정하고 기대 글자를 확인하세요. 글자를 읽을 수 없으면 **표 안의 완료 모양 고르기**에서 조회 중에는 사라졌다가 완료 시 나타나는 작은 표시를 지정합니다. 표 테두리, 항상 켜진 버튼, 매번 달라지는 데이터 값은 적합하지 않습니다. 조회 전부터 같은 표시라면 재생 중에 그 표시가 사라졌다 다시 나타나는 것도 관찰해야 진행합니다.
5. 파일 생성까지 확인하려면 **앱이 실제로 저장하는** 로컬 `.xlsx` 또는 `.xlsm` 파일 경로를 지정하세요. 파일명이 매번 바뀌면 이 작업만 사용하는 로컬 폴더를 지정하세요. 폴더 모드에서는 새 통합 문서가 정확히 하나 생겨야 합니다. **단계에 추가 → 저장**을 누릅니다. 파일을 지정하지 않아도 메뉴를 실행할 수 있지만 파일 생성은 확인되지 않습니다.

**다음부터는 한 문장이면 됩니다.** Claude Code에 **“FX 조회 내보내기를 Family=Hybrid로 실행해 줘”**라고 하세요. 변수 없이 요청하면 값을 먼저 받아야 하며, 그전에는 첫 단계도 실행하지 않습니다. 결과를 읽지 못하면 다음 단계로 넘어가지 않습니다. 표와 메뉴는 실제 마우스를 쓰므로 FX 창을 표시하고 재생 중에는 마우스나 키보드를 움직이지 마세요.

파일 확인은 256 MiB 이하의 통합 문서를 대상으로 합니다. 파일 감시는 저장 경로를 정해 주는 기능이 아닙니다. FX가 ‘다른 이름으로 저장’을 띄우거나 저장하지 않은 Excel 창만 연다면 직접 저장해야 합니다. `.xls`와 네트워크 폴더는 이 버전의 통합 문서 확인 대상이 아닙니다. 이전 버전에서 수동으로 남은 우클릭은 위 절차로 새 작업에 가르치세요. 회사 PC에서 처음 시험할 때는 내보낸 파일을 열어 선택한 Family의 결과가 맞는지도 확인하세요.

### 목록에서 특정 행의 버튼을 누르고 결과 확인하기

예를 들어 목록의 세 기기를 실행한다면, 먼저 관리자를 열고 실행할 세 행의 번호와 현재 상태를 확인하세요. 창 크기와 화면 배율은 시연할 때와 같게 두고 세 행이 화면에 보이게 하세요.

1. Claude Code에 **“이 창의 목록에서 행 버튼을 가르치는 녹화를 시작해 줘. 이름은 ‘기기 세 대 실행’이야.”**라고 요청합니다. 녹화 창에서 **행 버튼 가르치기 → 행 가져오기 (3초)**를 누르고 업무 창의 대상 행 위에 마우스를 둡니다.
2. 행 미리보기에서 세 곳을 지정하세요. **행을 구별하는 표시**에는 번호나 고유 이름, **클릭할 버튼**에는 ▶ 전체, **상태**에는 ‘부팅되지 않음’ 같은 현재 상태 글자를 담습니다. 다른 행에서도 계속 달라지는 숫자, 경과 시간, 포인터가 놓일 때만 나타나는 아이콘은 피하세요.
3. **실행 전 상태 기록**을 누른 뒤 업무 창에서 직접 버튼을 누르세요. 같은 행에 원하는 **최종 상태**가 보일 때 **완료 상태 가져오기 (3초)**를 누릅니다. ‘부팅 중’에서 기록하면 다음 실행부터 ‘부팅 중’을 완료로 판정하게 됩니다. **이 행에서 실행할 동작**에 `첫 번째 기기의 시작 버튼을 눌러 실행 중인지 확인`처럼 적고, 미리보기를 확인한 뒤 **단계에 추가**를 누르세요. 두 번째와 세 번째 행은 같은 버튼과 시작 상태라면 **이전 행의 완료 표시 사용**으로 시연을 줄일 수 있습니다. 행을 모두 추가하고 저장하세요.
4. **“기기 세 대 실행을 재생해 줘.”**라고 요청합니다. 재생은 가르친 행을 현재 화면에서 다시 찾고 마우스로 버튼을 한 번 누릅니다. 해당 행에서 완료 표시를 확인하면 다음 행으로 진행합니다. 이미 완료된 행은 클릭을 건너뜁니다. 중간에 멈추면 **“이 작업의 각 행 상태만 다시 확인해 줘.”**라고 요청하세요.

같은 이름의 버튼이 여러 줄에 있어도 행 번호나 이름이 구분되면 사용할 수 있습니다. 목록의 정렬 순서가 바뀌면 녹화한 번호나 이름을 따라갑니다. 담당자가 새로 상위에 올라온 행을 실행하고 싶다면 그 행을 다시 지정하세요. Windows가 목록의 행 경계를 제공하고, 버튼과 상태 표시를 화면에서 구분할 수 있어야 합니다. 작업 파일에는 직접 지정한 행 표식, 버튼, 전후 상태의 작은 화면 표본이 로컬에 저장됩니다. 행을 구별하는 데 필요한 부분만 담으세요.

### 녹화 없이 바로 지시하기

**처음에는 읽기만 해 보세요.** 회사 PC에서 실제 업무 화면을 연 뒤 다음처럼 요청합니다.

> desktop-select로 Device Setup Standard 업무 창에서 MES Setup과 Family가 각각 어느 콤보인지 보여 줘. 아직 값을 바꾸지 마.

대상이 맞으면 **“같은 창에서 MES Setup을 N으로, 확인되면 Family를 Hybrid로 선택해 줘”**라고 요청하세요. 쓰기 가능한 부모 콤보에 요청한 문자열을 한 번 설정한 뒤 값을 다시 읽습니다. 선택을 전달한 후에도 선택값을 읽을 수 없으면 거기서 멈춥니다. 화면에 있는 옵션 목록만으로 선택됐다고 판정하지 않습니다.

**조회나 메뉴:** “업무 폼 안의 조회를 눌러 줘”처럼 같은 이름의 두 버튼 중 원하는 쪽을 알려 줄 수 있습니다. 범위 이름은 `commands`(바깥 도구 모음), `content`(안쪽 업무 폼), `conditions`(조회 조건), `condition-commands`(조건 영역 명령), `grid`, `properties`입니다. 실제로 나타난 영역만 사용할 수 있습니다. 중첩 메뉴는 먼저 부모를 펼치고 실제로 나타난 자식을 선택합니다. 표 내부나 우클릭 메뉴가 접근성에 노출되지 않으면 사용자가 메뉴를 열어 준 후 보이는 항목부터 확인할 수 있습니다. 셀을 추측하거나 선택 범위를 바꾸지 않습니다. 우클릭으로 내보낼 때는 위 FX 절차에서 메뉴 경로와 파일 조건을 함께 가르치세요.

**마우스 사용 여부**는 단계에 따라 다릅니다. 콤보와 메뉴는 Windows 접근성 기능으로 조작합니다. 행 버튼과 표 우클릭 메뉴 재생은 대상 창을 앞으로 가져오고 실제 포인터를 이동해 클릭합니다. 실제 포인터를 쓰는 단계가 끝날 때까지 마우스와 키보드를 사용하지 마세요.

**콤보에서 어디까지 읽히나:** 특정 콤보를 확인하면 현재 접근성에서 읽히는 옵션 값과 이름을 보여 줍니다. 닫힌 콤보는 목록이나 현재값이 비어 보일 수 있습니다. SetValue를 지원하면 옵션 목록이나 펼침 상태에 의존하지 않고 요청한 실제 문자열을 씁니다. 표시명과 내부 코드가 다르면 실제 코드를 사용하세요. SetValue를 지원하지 않는 콤보만 필요한 경우 펼쳐서 현재 항목을 선택합니다. 해당 경로에서 항목의 소속이나 표시명이 모호하면 임의로 고르지 않습니다. 검색 전용 별도 대화상자는 추가 지시가 필요할 수 있습니다.

문제가 생겼을 때는 다음만 구분하면 됩니다.

| 표시 | 의미와 다음 행동 |
|---|---|
| `verified` | 해당 단계의 기대값 또는 상태가 일치했습니다. 파일 조건을 지정한 내보내기에서는 새로 생성되거나 변경된 Excel 통합 문서를 확인했습니다. |
| `blocked` | 명령을 완료하지 못했습니다. 창/필드 중복, 읽을 수 없는 옵션, 비활성 컨트롤 등을 확인하세요. `expanded: true`이면 목록만 펼쳤을 수 있습니다. |
| `delivered_unverified`, `mismatch`, `uncertain` | 호출 결과를 성공으로 단정하거나 다시 누르지 마세요. 화면을 보거나 같은 대상에 `inspect`로 읽기만 하세요. |

PowerShell에서 직접 시험할 때는 스킬 폴더에서 실행합니다. 아래 제목은 **첫 명령이 돌려준 실제 제목 전체**로 바꾸세요.

```powershell
Get-Process -Name '*MenuAgent*' | Select-Object -ExpandProperty ProcessName -Unique
$fx = '<위에서 확인한 MenuAgent 프로세스 이름>.exe'
python -X utf8 -B scripts/desktop_select.py windows --exe $fx
$screen = '<실제 업무 창 전체 제목>'
python -X utf8 -B scripts/desktop_select.py inspect --exe $fx --window $screen --target 'MES Setup' --role combobox
python -X utf8 -B scripts/desktop_select.py select --exe $fx --window $screen --target 'MES Setup' --value N
python -X utf8 -B scripts/desktop_select.py select --exe $fx --window $screen --target Family --value Hybrid
```

마지막 두 줄은 한 줄씩 실행해 결과를 확인하세요. 스킬은 해당 PC에서 동작하며, 출력은 명령을 실행한 Claude Code 세션에 보입니다.
