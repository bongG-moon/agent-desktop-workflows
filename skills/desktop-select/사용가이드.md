# Desktop Select 0.5.1 사용 가이드

## 설치와 버전 확인

Windows ZIP을 풀고 `desktop-select` 폴더 전체를 Claude Code 프로젝트의 `.claude/skills/`에 복사하세요. 이전 파일을 부분 수정해서 쓰고 있었다면 폴더 전체를 교체하고 새 대화를 시작하세요. 64비트 Python 3.10 이상과 Tkinter가 필요합니다. CUA 드라이버나 추가 EXE는 없습니다.

Claude Code에 **“desktop-select의 doctor로 설치 버전과 경로를 확인해 줘”**라고 요청하세요. `version: 0.5.1`과 실제 사용하는 스킬 위치가 나와야 합니다. doctor 명령이 없으면 이전 설치본을 실행하고 있는 것입니다. 저장된 작업은 기본적으로 `%LOCALAPPDATA%\DesktopSelect\tasks`에 있어 스킬 교체로 지워지지 않습니다.

## 녹화는 위치, 실행할 동작은 설명

새 녹화는 위치를 알려 주고 설명 작성을 돕는 용도입니다. 클릭이나 옵션 선택이 확인되면 자연어 초안을 채웁니다. 위치만 가리킨 콤보에 이미 보이던 Hybrid 같은 값은 고정값으로 추정하지 않습니다. 초안을 원하는 동작으로 수정하면 실행할 때 Claude Code가 현재 화면과 함께 해석합니다. 정해진 문장 형태에 맞출 필요가 없습니다.

1. 업무 창을 열고 **“desktop-select로 ‘FX 조회 내보내기’ 작업을 녹화해 줘”**라고 요청합니다.
2. **대상 추가 (3초)**를 누르고 업무 창의 콤보나 버튼 근처에 마우스를 둡니다. 클릭하거나 값을 바꿀 필요가 없습니다. 여러 위치를 클릭해서 알려 주려면 **시작 → 각 위치 클릭 → 마치고 검토**를 사용합니다. 실제 업무 버튼을 클릭하면 앱도 반응하므로, 위치만 가르칠 때는 3초 가리키기를 권장합니다.
3. 단계 옆의 **실행할 동작**에 자동으로 채워진 초안을 확인하고 원하는 문장으로 수정합니다. 직접 작성하거나 초안을 지워도 됩니다. 필요한 실행 변수는 변수 칸에 쉼표로 구분해서 적을 수도 있습니다.
4. **적용 후 다음**은 현재 설명을 반영하고 다음 단계로 이동합니다. **이전/다음**으로 다른 단계로 이동할 때도 현재 설명을 보존합니다. 다음 단계가 아직 없으면 **대상 추가 (3초)**로 새 위치를 추가하세요.
5. 모두 확인한 뒤 **전체 저장**을 누릅니다. 단계 이동과 전체 작업 저장은 별개입니다.

값이 읽히지 않는 콤보도 위치와 설명을 기록합니다. “직접 확인할 단계”로 바꾸고 문장을 거부하던 기존 방식과 다릅니다. 위치를 전혀 찾지 못했으면 **대상 지정 필요**로 표시되지만 설명은 작성하고 저장할 수 있습니다. 실행 전에 그 단계의 **대상 다시 지정**을 사용하세요.

초안은 성공 기록이 아니라 작성 보조입니다. 조회 버튼을 클릭했다면 조회 버튼 실행을, 결과 표를 우클릭했다면 우클릭을 설명합니다. 콤보에서 실제 N 항목을 클릭한 근거가 있으면 N 선택을 설명하지만, 값이나 옵션을 읽지 못하면 값을 채우지 않은 초안을 사용합니다. 확인되지 않은 조회 완료나 Excel 파일 생성까지 문장에 넣지 않습니다.

Family를 실행 변수로 쓸 때는 초안을 **“입력받은 {Family} 값을 이 항목에 설정해 줘”**로 바꾸세요. 한 번 수정한 문장과 변수는 이후 클릭이나 대상 재지정으로 덮어쓰지 않습니다. 자동으로 채워진 고정값 초안도 그대로 실행하기 전에 의도에 맞는지 확인하세요.

## FX 설정 예시

| 단계 | 가리킬 위치 | 실행할 동작에 적을 예시 | 실행 변수 |
|---|---|---|---|
| 1 | MES Setup 콤보 근처 | MES SETUP 조건을 N으로 설정해 줘 | 없음 |
| 2 | Family 콤보 근처 | 실행할 때 입력받은 변수를 FAMILY 조건에 넣어 줘 | Family |
| 3 | 조회 버튼 근처 | 이 조건으로 조회해 줘 | 없음 |
| 4 | 조회 결과 표의 데이터 본문 | 이 결과 표를 우클릭해서 EXPORT 다음 EXPORT TO EXCEL을 실행해 줘 | 없음 |

내부 이름이 gcboStatus여도 화면에 보이는 이름으로 설명하세요. 문장의 이름이 내부 ID와 다르다는 이유로 저장을 막지 않습니다. Claude Code가 지정한 위치 주변의 실제 요소를 보고 동작을 결정합니다.

저장한 다음 **“FX 조회 내보내기를 Family=Hybrid로 실행해 줘”**라고 요청하세요. 다음 번에는 **Family=DRAM**으로 바꿔 요청하면 됩니다. 변수가 빠졌다면 실행 전에 값을 물어보며, 이전에 보였던 Hybrid를 임의로 사용하지 않습니다. 단순한 조회 버튼 호출은 전달만 확인할 수 있습니다. 조회 결과나 Excel 파일이 실제로 완성됐다는 확인은 별도입니다.

표 우클릭의 위치는 실제 데이터를 선택하는 셀과 다를 수 있으므로, 특정 행만 내보내야 한다면 어느 행인지 설명에 적고 현재 화면에서 확인해야 합니다. 접근성에 식별 가능한 표 영역이 있으면 셀 자체의 ID가 없어도 메뉴를 열 수 있습니다. Excel이 파일 대신 새 창으로 열렸다면 파일 저장까지 됐다고 표시하지 않습니다.

## 잘못 기록한 단계 고치기

- **동작 수정**: 현재 단계의 설명과 실행 변수를 바꿉니다.
- **대상 다시 지정**: 설명은 유지하고 위치만 다시 가리킵니다.
- **단계 삭제**: 선택한 잘못된 단계를 목록에서 제거합니다.
- **전체 저장**: 편집한 단계 목록을 저장합니다.

저장한 뒤에도 **“desktop-select의 ‘FX 조회 내보내기’를 편집해 줘”**라고 요청할 수 있습니다. 수정 전 작업은 tasks 아래 history 폴더에 자동 보관됩니다. 다른 편집 창에서 먼저 저장한 내용은 덮어쓰지 않습니다. 예전 작업에서 Family가 고정 Hybrid로 저장됐더라도 다시 녹화할 필요 없이 설명을 변수 방식으로 고치면 됩니다.

## 실행 상태와 화면 사용

설명 해석에는 현재 사용 중인 Claude Code 모델을 사용합니다. 이 ZIP이 별도 외부 모델을 호출하지 않습니다. 일반 Python 명령만 실행하면 해석이 필요하다는 상태가 나올 수 있지만 Claude Code가 이어서 실행안을 만드는 흐름입니다. 사용자가 JSON을 작성할 필요는 없습니다.

- **verified**: 해당 값이나 지정한 결과가 다시 확인됐습니다.
- **completed_unverified**: 요청한 버튼/메뉴는 전달됐지만 모든 업무 결과까지 확인된 것은 아닙니다.
- **needs_input**: 실행에 필요한 변수값이 없습니다.
- **needs_interpretation**: Claude Code가 자유문장을 실행 동작으로 해석하는 차례입니다.
- **needs_target**: 설명은 저장됐지만 위치를 다시 지정해야 합니다.
- **needs_instruction**: 초안으로 저장한 단계에 실행할 동작을 적어야 합니다.
- **uncertain**: 호출 결과가 불명확합니다. 같은 작업을 다시 누르지 말고 현재 상태를 확인합니다.

최소화된 창은 조작 시 복원하며 inspect는 창을 복원하지 않습니다. 행 버튼과 표 우클릭은 실제 포인터를 사용하므로 실행 중 마우스와 키보드를 사용하지 마세요.

## 선택 사항: 결과까지 검증하도록 자세히 가르치기

**조회 후 우클릭 메뉴 가르치기**에서는 조회 완료 글자 또는 그림, 우클릭 위치, 메뉴 경로, 실제 출력 파일/폴더를 지정합니다. 이 상세 단계는 새 결과가 확인된 뒤에만 메뉴를 실행합니다. 지정 파일은 실제 앱이 저장하는 로컬 .xlsx 또는 .xlsm이어야 하며 256 MiB 이하를 확인합니다. 앱의 저장 설정을 바꾸거나 저장 대화상자를 자동 승인하는 기능은 아닙니다.

**행 버튼 가르치기**에서는 행을 구별하는 표시, 버튼, 실행 전후 상태를 지정합니다. 위치와 자유문장만으로 시작한 뒤, 더 정확한 완료 확인이 필요할 때 사용하는 선택 기능입니다.
