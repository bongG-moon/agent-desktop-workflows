# Desktop Select 0.4.9 — 입력 방식 확인과 백그라운드 전용 실행

0.4.0 태그(`02fa20e`)에서 다시 구성한 실행기에 자연어 녹화와 실행안 저장을 연결했습니다. 처음에는 위치를 녹화하고 설명 초안을 수정한 뒤 Python 업무 스킬로 등록합니다. 이후에는 Family 같은 선택값과 SearchText 같은 입력값을 받아 같은 순서로 실행합니다. 0.4.9는 실행 전에 입력 방식을 확인하고, 필요할 때 도구의 물리 입력과 전면화를 금지할 수 있도록 보완합니다. 기본 조회와 Excel 내보내기 흐름은 유지합니다. 기존 CUA MCP와 별도이며 CUA 드라이버가 필요하지 않습니다. ZIP에는 Python 소스를 포함한 텍스트 파일만 있습니다.

Claude Code에 “MES Setup은 N으로 고정하고 Family는 실행할 때 받아 줘. 조회 뒤 결과 표를 우클릭해서 Excel로 내보내고, 저장 창과 파일 확인까지 Python 업무 스킬로 연결해 줘”라고 요청하세요. 호스트 모델이 현재 화면을 확인해 실행안을 한 번 정리하고, 반복 실행은 저장한 동작을 Python으로 수행합니다. 외부 모델 호출은 없으며 업무 앱의 서버 처리 시간은 줄이지 않습니다. 회사 PC에는 64비트 Python 3.10 이상이 필요하며 녹화 창은 Tkinter를 사용합니다. ZIP의 `desktop-select` 폴더 전체를 프로젝트의 `.claude/skills/` 아래에 넣으세요. [Windows ZIP 다운로드](https://github.com/bongG-moon/agent-desktop-workflows/releases/download/desktop-select-v0.4.9/desktop-select-0.4.9-windows-x64.zip) | [한국어 사용 가이드](https://github.com/bongG-moon/agent-desktop-workflows/blob/desktop-select-v0.4.9/skills/desktop-select/사용가이드.md)

정확한 ID나 이름이 없는 입력란은 확인된 상위 영역과 그 안의 상대 위치를 기록할 수 있습니다. 실행 때 영역과 실제 UIA 대상의 역할, 클래스, 소속을 다시 확인합니다. 임시 HWND를 저장하거나 옛 절대좌표를 누르지 않습니다. 표준 Win32 우클릭 메뉴는 대상 창의 실제 메뉴 소유자를 확인한 뒤 읽습니다. 이름 있는 표 영역과 완료 표식, 메뉴 항목은 필요한 후보만 조회해 전체 화면 반복 탐색을 줄입니다.

**0.4.5의 프로젝트별 저장은 그대로 유지합니다.** 프로젝트의 `.desktop-select/tasks`와 그 아래 `execution-plans`를 사용하므로 실행 명령을 어느 폴더에서 시작해도 설치한 프로젝트의 작업을 찾습니다. `storage` 명령으로 실제 저장 위치를 확인할 수 있습니다. 별도 설치 질문 없이 프로젝트 저장이 기본이며, 공용 저장을 원하는 경우에만 `DESKTOP_SELECT_TASK_DIR`을 명시합니다. 기존 사용자 공용 녹화를 자동으로 가져오거나 삭제하지 않습니다.

`record` 저장 시 호환되는 작업의 실행안도 저장합니다. `plan --task`로 기존 작업에서 만들 수 있고 `instruct --save-as`는 지시를 수정한 새 작업을 만듭니다. 원본이 바뀌면 이전 실행안은 사용하지 않습니다. 콤보, 일반 입력란, 버튼, 대기로 구성된 녹화는 Python 등록으로 연결됩니다. **기존 녹화의 `result-menu`, 행, 수동 단계는 새 형식으로 자동 변환되지 않습니다.** 해당 작업 전체는 기존 재생 경로를 사용합니다. 새 우클릭/팝업 연결은 현재 화면을 확인해 `register --recipe`로 별도 등록합니다.

등록은 읽기 전용입니다. 아직 열리지 않은 저장 창의 단계는 `pending_scopes`로 남으며 실제 실행 때 소속과 대상이 확인되어야 진행합니다. 표 우클릭은 실제 마우스를 사용하고 `submit`은 지정 입력란에 Enter를 보냅니다. 이름 없는 입력란을 상대 위치로 찾을 때도 창을 앞으로 가져옵니다. 이 단계 중에는 마우스와 키보드를 사용하지 마세요. 일반 값 설정과 버튼 호출은 접근성 API를 사용합니다. 파일 확인은 새로 생성되거나 변경된 통합 문서 구조를 확인하며 조회 내용의 정확성과는 구분합니다.

`scripts/run.py --input-plan`으로 앱을 실행하지 않고 입력 방식을 확인할 수 있습니다. `--background-only`는 우클릭, Enter 또는 위치 기반 대상이 포함된 전체 요청을 첫 입력 전에 거절하며 최소화된 창도 복원하지 않습니다. 허용된 UIA 실행에서는 자동 포커스를 끕니다. 옵션을 생략하면 기존 방식으로 실행합니다. 앱이 스스로 창을 열거나 포커스를 바꾸는 동작까지 격리하는 기능은 아닙니다. [원본 스킬과 CUA 입력 방식 비교](docs/desktop-select-input-modes.md)를 참고하세요.

핵심 변경은 `IsOffscreen=None` 보정, 동일한 편집 피어 값의 일치 판정, 쓰기 가능한 콤보의 SetValue 1회 후 확인, 조작 전 최소화 창 복원입니다. 먼저 펼침과 항목 선택을 시도하던 경로를 줄였습니다. 일반 값/버튼 단계는 UIA 연결을 재사용하고 저장한 ID 또는 정확한 이름과 역할로 조회한 뒤 현재 상위 영역을 확인합니다. 핵심 브리지와 녹화기는 0.4.0 그대로 유지하며 호환 코드는 별도 파일로 분리했습니다. [0.4.0 대비 변경과 검증](docs/desktop-select-040-rebuild.md)을 참고하세요.

고정값으로 등록한 MES Setup=N은 매번 유지되고, 필수 변수로 등록한 Family와 SearchText만 실행 때 바뀝니다. 예: `scripts/run.py --set "Family=Hybrid" --set "SearchText=00123"`. 필요한 값이 빠지면 실행 전에 함께 묻습니다. 일반 입력란은 `--set "SearchText="`로 비울 수 있지만 콤보의 빈 값은 허용하지 않습니다. 고정값도 바꾸어 받고 싶다면 등록 지시부터 필수 변수로 바꾸세요. 기존 방식의 조회 완료 표시와 우클릭은 녹화 창의 **조회 후 우클릭 메뉴 가르치기**를 사용합니다. Desktop Select ZIP은 `python tools/build_desktop_select.py`로 빌드할 수 있습니다.

새 입력 정책과 커서/포커스 보존 시험은 [0.4.9 검증 기록](docs/desktop-select-049-validation.md)에 기록합니다. 기존 실제 DBeaver 시험과 속도 측정은 [0.4.8 검증 기록](docs/desktop-select-048-validation.md)에 보존합니다. 이 PC의 시험은 회사 FX와 FarPoint 제공자의 실검증을 대신하지 않습니다.

목록 안의 버튼은 행 번호나 이름, 버튼 모양, 실행 전후 상태를 한 번 가르치면 재생할 수 있습니다. 실행 중에는 실제 마우스를 사용하고 같은 행에서 완료 표시를 다시 읽습니다.

## Agent Desktop Workflows 0.1.6 녹화 도구

**0.1.6부터는 콤보 항목의 접근성 이름과 실제 값이 달라도 선택값을 기록합니다.** 예를 들어 사용자가 누른 항목의 내부 이름이 `Item 1`이고 값이 `N`이면 녹화에는 `N`이 남습니다. 목록 펼치기를 지원하는 콤보의 새 마우스 선택 단계는 재생할 때 현재 콤보의 목록에서 이번 입력값과 일치하는 보이는 항목을 찾아 한 번 클릭합니다. 항목의 소속이나 위치가 불확실하면 클릭하지 않고, 클릭 후 값을 읽지 못하면 자동 확인하지 않습니다. 이전 녹화는 [두 콤보 단계만 보완하는 방법](사용가이드.html#combo-value-repair)을 참고하세요.

**0.1.5는 특정 앱의 필드명에 의존하지 않고 콤보 선택 과정을 기록합니다.** 클릭한 옵션과 소속 콤보의 관계가 확인되면, 부모 값이 비어도 선택 의도를 저장합니다. 녹화 당시의 적용 확인/미확인/불일치를 별도로 표시하며 재생 성공은 매번 실제 값으로 검사합니다. 명시적 라벨 연결과 선택 컨테이너 관계를 사용하고, 인접한 같은 이름의 옵션이나 취소한 선택을 임의로 합치지 않습니다. 기존 빈 값 작업은 자동 수정하지 않으므로 필요한 단계만 새로 녹화하거나 보완하세요.

**0.1.4는 콤보의 이름은 인식하지만 선택값이 빈 문자열로 녹화되는 문제를 보완합니다.** 부모의 빈 값만으로 선택값을 확정하지 않고, 같은 콤보에서 명시적으로 선택된 항목이나 하위 편집기 값의 근거를 확인합니다. 읽을 수 없으면 대상 이름을 유지한 보완 단계로 남깁니다. 기존 빈 콤보값은 입력 전에 차단하며, 실제 값이 반영되지 않은 실행은 성공 처리하거나 자동 반복하지 않습니다. 이미 저장된 잘못된 값은 자동 복원하지 않으므로 [콤보 값 보완 안내](사용가이드.html#combo-value-repair)에 따라 새 수정본으로 저장하세요.

[Agent Desktop Workflows 0.1.6 소스와 녹화 가이드](https://github.com/bongG-moon/agent-desktop-workflows/tree/v0.1.6)

Windows 업무를 한 번 직접 녹화하고, 인식되지 않은 단계만 보완한 뒤 작업 이름과 조건으로 실행하는 독립 시스템입니다. **기존 CUA MCP와 별도 실행 파일, 설정, 작업 저장소를 사용합니다.** CUA MCP 서버나 CUA Driver를 설치/실행하지 않습니다.

처음 사용하는 분은 Windows ZIP 전체를 새 로컬 폴더에 풀고 **`사용가이드.html`**을 여세요. `Start.cmd`로 녹화/편집 화면을 실행합니다. 64비트 Python 3.10 이상과 tkinter는 회사에서 승인한 환경에 별도로 준비해야 합니다.

**0.1.3은 FX 실습 가이드를 추가한 문서 업데이트입니다.** [사용가이드의 FX 실습](사용가이드.html#fx-walkthrough)에 Family=Hybrid, Status=N 설정부터 조회, 표 우클릭 Excel 내보내기, 첫 UI 실행과 Claude Code 재사용까지의 순서를 담았습니다. 입력 변수와 완료 조건 설정표, 사람 확인 후 이어하기 요청문을 포함합니다. ZIP 안의 가이드와 릴리즈의 별도 HTML 가이드에 같은 내용을 제공합니다. 실행 동작과 기존 EXE는 0.1.2와 같습니다.

**0.1.2는 녹화와 재개 흐름을 보완한 버전입니다.** 콤보 목록 선택과 독립된 행 선택을 기록하고, 제출 버튼이 입력창을 비워도 제출 전 관찰한 값을 보존합니다. 빠른 입력 때문에 전환 전 값의 근거가 부족하면 보완 단계로 남깁니다. 이어하기는 현재도 필요한 최신 조건을 확인하고, 아직 입력하지 않은 작업의 파일 기준값을 새로 잡습니다. 실행 기록을 보는 중에는 **최신 수정본 보기**로 전환해 내용을 확인한 뒤 새 작업을 실행합니다.

이전 버전에서 누락되거나 잘못 녹화된 동작은 업데이트만으로 원래 의도를 복원할 수 없습니다. 기존 작업의 콤보 선택, 제출 전 입력, 목록 선택을 확인하고 문제가 있는 단계만 다시 녹화하세요. 이전 원본과 수정본은 유지됩니다.

**0.1.1에서는 자체 도우미 EXE를 제거하고 창 조회, 녹화와 영역 입력을 공개된 Python 소스로 실행합니다.** Windows ZIP의 EXE는 이전 Agent Desktop Local 0.2.0에 포함된 것과 동일한 `bin/agent-desktop.exe` 하나입니다. 실행 중 EXE/DLL을 생성하거나 내려받지 않고, Python 표준 라이브러리로 Windows 기본 API를 호출합니다. 새 미서명 도우미의 배포 의존성을 없앤 변경이며 회사 보안 정책의 허용 여부를 보장하는 것은 아닙니다.

Main의 **Code → Download ZIP** 또는 소스 ZIP을 사용하는 경우에도 자체 도우미를 빌드할 필요는 없습니다. 이전에 받은 Agent Desktop Local 0.2.0의 `bin/agent-desktop.exe`를 새 제품 폴더의 `bin/agent-desktop.exe`로 직접 복사하고 `UPSTREAM.json`의 SHA-256과 일치하는지 확인하면 됩니다. 이전 설치 폴더는 그대로 두며, 이 제품이 기존 설치나 설정을 자동으로 탐색하거나 가져오지 않습니다. 일반 요소 실행 전에도 해당 바이너리의 해시를 검사합니다.

## 사용 흐름

1. 업무 창을 선택하고 **새 작업 녹화**를 누릅니다.
2. 녹화 도우미에서 시작을 누르고 실제 업무를 직접 수행합니다. 인식 상태와 보완 안내를 확인합니다.
3. 녹화를 마친 뒤 조건값을 입력 변수로 지정하고 완료 조건을 검토합니다.
4. 문제가 있는 부분은 **단계 수정** 또는 **이 단계 다시 녹화**로 보완합니다. 영역 대상은 실제 대상과 내부 위치를 확인하고 단계 수정창의 확인란을 체크해 저장합니다. 이전 기록은 유지됩니다.
5. UI의 **작업 실행**, 또는 Claude Code에서 저장한 작업 이름과 조건으로 실행합니다.

> 저장한 ‘Device 조회 후 Excel 내보내기’를 Family=Hybrid, Status=N으로 실행해 줘. 대상 업무 창을 먼저 확인하고, 결과가 불명확한 단계는 멈춰서 알려 줘.

단계마다 자연어로 요소를 설명하거나 ref를 복사할 필요가 없습니다. 로컬 실행기가 현재 대상을 다시 찾아 조작하고 결과를 확인합니다. 지원하지 않는 단계는 수동 단계로 보관할 수 있고, 사용자가 완료한 뒤 다음 단계부터 이어갑니다.

## 포함된 기능

- 별도 녹화 도우미와 작업/단계 편집 UI
- 녹화 중 대상 인식, 조작 방식, 결과 확인의 구분
- 입력 변수, 단일 단계 재녹화와 수정 이력
- 현재 요소를 다시 찾는 작업 단위 실행
- 녹화된 영역에 한정한 ref 없는 대상의 지역 입력
- 불확실한 실행의 자동 반복 방지, 중단 기록과 이어하기
- CLI와 Claude Code용 스킬, 오프라인 사용 가이드

녹화 중 표시되는 ‘요소 후보’는 실제 재생 성공을 뜻하지 않습니다. `completed_unverified`는 실행 전달은 진행됐지만 일부 업무 결과가 확인되지 않았다는 뜻입니다. 조회와 저장, 내보내기에는 실제 완료 신호를 지정하거나 해당 단계에 사람 확인을 둡니다.

## Claude Code에서 사용

새 프로젝트의 `.claude/skills/agent-desktop-workflows/`에 폴더 내용 전체를 복사하거나, 이 폴더의 `SKILL.md` 전체 경로를 명시해서 읽게 합니다. 기존 `agent-desktop-local`과 다른 이름입니다. 기존 CUA 스킬이나 개인 모델 설정을 덮어쓰지 않습니다. 설치 방식은 [Claude Code 공식 문서](https://code.claude.com/docs/en/skills)를 따릅니다.

명령과 결과 파일은 [references/usage.md](references/usage.md)에 있습니다. 채팅 전용 모델은 PC를 조작할 수 없으며 로컬 파일과 명령 실행 도구가 있는 환경이 필요합니다. 모델 주소, 인증, MCP, hooks와 전역 권한을 이 제품 때문에 바꾸지 않습니다.

## 자료와 경계

기본 저장소는 `%LOCALAPPDATA%\AgentDesktopWorkflows`이며 기존 CUA 저장소를 읽거나 수정하지 않습니다. 녹화 원본, 작업 수정본과 실행 기록은 별도로 저장합니다. 업무 데이터, 입력값과 관찰 결과는 회사에서 승인한 사내 모델 환경에서만 읽습니다.

제품 코드에는 외부 모델/API, JEV, 원격 로그, 자동 업데이트, npm 설치 또는 상시 감시 서비스가 없습니다. Python 녹화 도우미는 녹화 동안 Windows 입력 이벤트를 관찰하고 선택한 창의 동작을 기록합니다. 호스트 모델이나 동기화 폴더의 외부 전송을 OS 차원에서 막는 도구는 아닙니다. 회사 정책이 실행/캡처를 차단하면 우회하지 않습니다.

표 셀이 접근성에 노출되지 않으면 특정 행/셀 작업은 제한될 수 있습니다. 지역 입력은 현재 다시 식별한 녹화 영역에만 적용하며, 고정 좌표나 다른 창으로 대체하지 않습니다. 메뉴 항목을 읽을 수 있다는 사실도 실제 실행 가능성을 보장하지 않습니다. 실제 FX/FxMenuAgent와 회사 업무 결과는 현장 인수 시험이 필요합니다.

실행 엔진 agent-desktop 1.1.0의 원본 바이너리를 고정해 포함합니다. `UPSTREAM.json`, `LICENSE`, `NOTICE.txt`, `THIRD_PARTY_NOTICES.txt`에서 출처와 고지를 확인할 수 있습니다. 회사 정책은 Python 실행과 입력 관찰에도 그대로 적용됩니다. [Python 도우미 규약](references/backend.md)은 소스 검토와 개발 시 참고하세요.

0.1.0의 녹화 원본, 작업 수정본, 실행 기록 형식과 기본 저장소를 유지합니다. 새 버전은 새 프로그램 폴더에 풀고 같은 작업 저장소를 사용하세요. [검증 범위와 재현 방법](references/validation.md)을 확인하세요.
