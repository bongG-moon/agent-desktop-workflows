# Desktop Select 0.4.10 행 버튼 검증 기록

2026년 11월 15일 Windows에서 MuMuPlayer 관리 창의 첫 번째와 두 번째 기기를 대상으로 일반 녹화와 자연어 실행을 시험했다.

게시할 Windows ZIP을 새 경로에 풀어 일반 녹화부터 Python 스킬 등록과 실행까지 14개 검사를 통과했다. 이 WinForms 시험 앱에서 등록은 0.978초, 생성된 Python으로 정지된 두 행을 실행하고 상태를 확인하는 데는 3.107초가 걸렸다. 각각 프로세스 시작을 포함한 한 번의 측정이다. 같은 소스의 전체 회귀 시험은 723개가 통과했다.

## 실제 MuMuPlayer

0.4.9에서 저장한 작업을 열어 보니 네 단계 모두 `stable_locator_unavailable`로 남아 있었다. 사용자가 두 단계에 적은 실행 문장은 별칭에 들어 있었고, 실행 설명에는 입력창의 안내 문구가 저장돼 있었다. 이 작업을 기존 방식으로 재생하면 첫 단계에서 검토를 요청하고 입력을 보내지 않았다.

새 버전에서는 관리 창의 맨 위 두 기기가 정지된 상태에서 일반 녹화를 시작했다. Desktop Select에 첫 번째 행과 두 번째 행의 실행 버튼을 각각 누르도록 지시했다. 시험에는 MuMu 전용 명령을 사용하지 않았다.

| 확인한 항목 | 관찰 결과 |
|---|---|
| 자연어 지시로 실제 실행 | 각 행에서 실행 아이콘을 찾아 실제 포인터로 한 번씩 눌렀다. 이 시험에서 설정한 15초 안에는 상태를 확인하지 못해 두 호출 모두 `delivered_unverified`를 반환했다. |
| 기기 실행 결과 | 후속 관찰에서 두 행의 상태가 바뀌고 새 기기 창 두 개가 열린 것을 확인했다. 각 행의 실행 전후 상태를 캡처한 간격은 약 25초였다. |
| 일반 녹화 | 각 클릭이 어느 행의 버튼인지 식별하고, 실행 뒤 바뀐 행 상태를 함께 담은 두 단계를 저장했다. |
| 이미 실행 중인 작업 재생 | 저장한 두 단계를 다시 재생하자 두 행 모두 `observed_state=after`, 전체 `verified`였다. `input_dispatched=false`로 추가 클릭은 0건이었다. |

이 시험에서 처음 실행하는 버튼은 사용자의 실제 포인터를 쓴다. 두 기기 창이 뜬 후 관리 창으로 돌아와 각 행을 다시 확인했다. 위의 25초는 두 관찰 사이의 간격이다. 기기별 기동 시간은 따로 측정하지 않았다.

## Windows 시험 앱에서 행 순서를 바꾼 재생

실행 버튼과 상태 글자를 각 행 안에 직접 그리는 WinForms 목록을 만들었다. 접근성 API가 세 행에 같은 이름을 반환하고, 실행 버튼은 독립된 버튼으로 나타나지 않는 조건이다. 시험 앱은 어느 행에서 실행 버튼이 눌렸는지 별도로 센다.

| 시험 | 결과 |
|---|---|
| 일반 녹화와 저장 | 첫 번째와 두 번째 행의 버튼을 한 번씩 눌렀다. 실행 전후의 상태가 포함된 행 동작 두 건을 저장하고 다시 불러왔다. |
| 순서가 바뀐 뒤 재생 | 첫 행을 세 번째로 옮기고 모든 행을 정지 상태로 초기화했다. 재생은 처음 가르친 두 행만 각각 한 번 실행했고, 나머지 행의 실행 횟수는 0이었다. 두 행 모두 실행 후 상태까지 일치했다. |
| 연속 재생 | 이미 실행한 작업을 즉시 반복했을 때 세 행의 실행 횟수가 그대로였다. |
| Python 스킬 등록 | 녹화 작업을 등록하고 생성된 `scripts/run.py`를 실행했다. 입력 방식 미리보기에는 실제 포인터가 표시됐고, 초기화된 목록에서는 가르친 두 행만 실행됐다. |
| 이전 작업의 자연어 문장 | 0.4.9 형식으로 첫 단계 별칭에 “첫번째 요소 실행버튼 누르기”, 두 번째 단계 설명에 “두 번째 행을 실행해 줘”를 저장했다. 실행 시점 목록의 첫 두 행만 한 번씩 실행됐다. 재실행 입력은 0건이었고 원래 저장한 작업 내용을 보존했다. |

위 경로의 판정 14개가 모두 통과했다. 다음 명령으로 재현할 수 있다. `--work-dir`에는 아직 존재하지 않는 절대 경로를 지정한다. 시험이 끝나면 시험 창이 닫히고 결과 JSON이 그 폴더에 남는다.

```powershell
python -X utf8 -B tools/smoke_painted_rows.py --include-workflow --include-legacy --work-dir C:\Temp\desktop-select-painted-rows
```
